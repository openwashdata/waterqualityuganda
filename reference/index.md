# Package index

## Data

Access the waterqualityuganda datasets

- [`borehole_visits`](https://openwashdata.github.io/waterqualityuganda/reference/borehole_visits.md)
  : borehole_visits: Field visits to borehole sources
- [`household_visits`](https://openwashdata.github.io/waterqualityuganda/reference/household_visits.md)
  : household_visits: Field visits to households using a borehole
- [`labblanks`](https://openwashdata.github.io/waterqualityuganda/reference/labblanks.md)
  : labblanks: Laboratory blanks run alongside the water samples
- [`samples`](https://openwashdata.github.io/waterqualityuganda/reference/samples.md)
  : samples: Water samples and their E. coli results
